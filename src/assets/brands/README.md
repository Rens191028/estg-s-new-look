# Merklogo's

Plaats hier de officiële logo's (SVG, of PNG met transparante achtergrond) met exact deze bestandsnamen:

ja-solar, trina-solar, sungrow, huawei, solaredge, enphase, sma, growatt, byd, alfen,
charge-amps, daikin, k2-systems, sigenergy, aiko, enstall (bijvoorbeeld `sungrow.svg`).

Haal ze bij de officiële perspagina of het logopakket van het merk, of vraag ze via de distributeur.
Een merk zonder bestand toont gewoon de merknaam als tekst.
